У меня выдало ошибку swapon --show ( команда не найдена) это скорее всего связна с тем, что утилита swap нету на моей системе. Нашел команду альтернативу cat /proc/swaps, что показывает те же данные(Filename, Type, Size, Used, Priority) что и swap.


Вопрос 1)
~~~
fallocate - выделяет место на диске
mkswap - форматирование под swap
swapon - активирует подкачку
~~~

Вопрос 2)
~~~
swappiness - это параметр ядра, который определяет насколько агрессивно система будет выгружать данные из оперативной памяти в файл подкачки.
60 - это стандартная настройка. Система начнет активно использовать swap, когда оперативная память заполнится примерно наполовину. Раньше перекидывает данные на допустим HDD для освобождения RAM.
10 - система будет использовать физическую RAM максимально долго и обратится к swap только тогда, когда память будет заполнена почти полностью. Проще говоря дольше оставляет данные в RAM для быстрого использования.
~~~

Вопрос 3)
~~~
Для серверов баз данных swap иногда рекомендуют отключать, потому что выгрузка данных на диск вместо оперативной памяти вызывает огромное падение производительности.
~~~
